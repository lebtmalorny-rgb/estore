# Образы QCOW2, OVA и VMDK для Huawei OceanStor eStor T10 и T35

Для эмуляции **Dorado6000 V3** используйте комплект **T10**. Для **Dorado V6** доступны три варианта T35. Если нужен DeviceManager с английским языком по умолчанию, выбирайте **T35-EN**. Чтобы воспроизвести заводскую поставку, выбирайте **T35-HuaweiCloud** или **T35-FusionCompute** в зависимости от исходной платформы.

Для KVM и Proxmox используйте пару QCOW2. Для VMware ESXi подготовлены два OVA, для T10 и T35 EN. Образы передаются отдельно от документации. Заводской OVA T35 предназначен для Huawei FusionCompute.

## Диски QCOW2

Для одной ВМ возьмите оба файла из одной строки. В колонках указана ёмкость, которую увидит гостевая ОС. Все восемь файлов вместе занимают около 4,5 ГиБ. У каждого образа QCOW2 собственное содержимое, внешний базовый образ не требуется.

| Комплект | Системный диск, первый в порядке загрузки | Диск данных, второй |
|---|---|---|
| T10 | `T10-system.qcow2` · 20 ГиБ | `T10-data.qcow2` · 40 ГиБ |
| T35 Huawei Cloud | `T35-HuaweiCloud-system.qcow2` · 20 ГиБ | `T35-HuaweiCloud-data.qcow2` · 240 ГиБ |
| T35 FusionCompute | `T35-FusionCompute-system.qcow2` · 20 ГиБ | `T35-FusionCompute-data.qcow2` · 240 ГиБ |
| T35 EN | `T35-EN-system.qcow2` · 20 ГиБ | `T35-EN-data.qcow2` · 240 ГиБ |

**Диск данных при поставке пустой.** При первом запуске eStor может автоматически отформатировать его в ext3. Используйте для каждой ВМ свою копию пары дисков. Оригиналы пригодятся для повторного развёртывания.

## Пакеты OVA

OVA объединяет описание виртуальной машины (OVF) и её диски в одном архиве. В таблице указан размер файла OVA для передачи. Ёмкости системного диска и диска данных указаны отдельно и в порядке подключения.

| Платформа и комплект | Файл для импорта | Размер OVA | Диски внутри |
|---|---|---:|---|
| VMware ESXi · T10 v2 | `OceanStor_eStor_T10_ESXi_v2.ova` | 391 МиБ | VMDK, 20 + 40 ГиБ |
| VMware ESXi 8 · T35 EN | `OceanStor_eStor_T35_ESXi8_EN.ova` | 691 МиБ | VMDK, 20 + 240 ГиБ |
| Huawei FusionCompute · T35 | `FusionCompute_OceanStor_eStor_V1R1C00T35_single_controller.ova` | 727 МиБ | Huawei ZVHD, 20 + 240 ГиБ (`vda.vhd` и `vdb.vhd` в конце имён) |

В vSphere откройте **Deploy OVF Template**, выберите OVA для нужной версии и сопоставьте сети шаблона с порт-группами стенда. Перед первым включением проверьте, что загрузочным выбран системный диск на 20 ГиБ в позиции SCSI 0:0, а диск данных подключён в SCSI 0:1. Для T35 EN укажите один сокет с восемью ядрами. В его OVF задано общее число vCPU, топологию сокетов нужно проверить после импорта. Порядок импорта описан для каждого пакета. [Инструкция T10](../OceanStor_eStor_T10_ESXi_v2/IMPORT.txt) · [Инструкция T35 EN](../OceanStor_eStor_T35_ESXi8_EN/IMPORT.txt)

Заводской OVA FusionCompute использует VirtIO и формат дисков Huawei ZVHD. Для запуска этой версии на KVM уже подготовлена пара `T35-FusionCompute` из таблицы QCOW2. Облачный T35 поставлялся в формате QCOW2 под именем `HUAWEICLOUD_OceanStor_eStor_V1R1C00T35_single_controller.qcow`.

## Отдельные диски VMDK

Если для импорта в VMware выбрана распакованная версия пакета, положите в одну папку OVF, манифест MF и оба VMDK из одной строки. Укажите OVF в мастере импорта. Мастер развернёт транспортные диски `streamOptimized` в рабочие диски ВМ на datastore.

| Комплект | Описание ВМ и манифест | Системный VMDK · SCSI 0:0 | VMDK данных · SCSI 0:1 |
|---|---|---|---|
| T10 v2 | `OceanStor_eStor_T10_ESXi_v2.ovf` · `OceanStor_eStor_T10_ESXi_v2.mf` | `OceanStor_eStor_T10-system.vmdk` · 20 ГиБ | `OceanStor_eStor_T10-data.vmdk` · 40 ГиБ |
| T35 EN | `OceanStor_eStor_T35_ESXi8_EN.ovf` · `OceanStor_eStor_T35_ESXi8_EN.mf` | `OceanStor_eStor_T35-system.vmdk` · 20 ГиБ | `OceanStor_eStor_T35-data.vmdk` · 240 ГиБ |

При подготовке пакетов использовались исходный и промежуточный VMDK. У обоих формат `monolithicSparse` и виртуальная ёмкость 20 ГиБ.

- **T10.** Исходный VMDK `Vmware_OceanStor_eStor_V1R1C00T10_single_controller.vmdk` содержит только системный диск. Из него сделан `T10-system.qcow2`. Файл с суффиксом `.vmdk 2` побайтово совпадает с исходным.
- **T35 EN.** Промежуточный системный диск `esxi-system-working.vmdk` использовался при сборке OVA. Его гостевые данные совпадают с `OceanStor_eStor_T35-system.vmdk` из пакета.

## Происхождение комплектов

- **T10.** Одноконтроллерный Dorado6000 V3, версия `V300R003C00`. Системный QCOW2 получен из `Vmware_OceanStor_eStor_V1R1C00T10_single_controller.vmdk`. Его гостевое содержимое также совпадает с системным диском пакета `OceanStor_eStor_T10_ESXi_v2`. Из этого пакета взят диск данных на 40 ГиБ.
- **T35 Huawei Cloud.** Заводской облачный образ одноконтроллерного Dorado V6. Исходный файл `HUAWEICLOUD_OceanStor_eStor_V1R1C00T35_single_controller.qcow` уже имел формат QCOW2. Системный файл в комплекте побайтово совпадает с ним. В манифесте этой сборки указаны `6.1.2` и `V600R005C11`. В облачной поставке был только системный диск. Для локальной ВМ добавлена отдельная копия пустого диска на 240 ГиБ из пакета T35 EN.
- **T35 FusionCompute.** Оба диска восстановлены из одноимённого заводского пакета Huawei. В OVF системный диск обозначен как `vda`, диск данных как `vdb`. Исходные файлы с расширением `.vhd` содержали сжатые блоки Huawei ZVHD. Блоки обоих дисков распакованы и сверены с итоговыми QCOW2.
- **T35 EN.** Локальная адаптация T35 Huawei Cloud из пакета `OceanStor_eStor_T35_ESXi8_EN`. В системном диске изменены пути загрузки и монтирования для SCSI. DeviceManager выбирает английский по умолчанию для нового сеанса, ручной выбор языка сохраняется. Оба QCOW2 получены из VMDK этого пакета.

## Параметры виртуальной машины

Для всех четырёх вариантов используйте BIOS. Сначала подключите `system` и выберите его загрузочным, затем подключите выделенный `data` к той же шине. Модель контроллера особенно важна для T35, поскольку гостевые скрипты обращаются к дискам по именам устройств.

| Комплект | Процессор и память | Контроллер и порядок дисков | Сетевые адаптеры |
|---|---|---|---|
| T10 | 4 vCPU, 8 ГиБ | LSI Logic Parallel SCSI, позиции 0 и 1 | 6 × E1000 |
| T35 Huawei Cloud | 1 сокет × 8 ядер, 16 ГиБ | VirtIO Block, `virtio0` и `virtio1` | 5 × VirtIO |
| T35 FusionCompute | 1 сокет × 8 ядер, 16 ГиБ | VirtIO Block, `vda` и `vdb` в OVF | 5 × E1000 по описанию OVF |
| T35 EN | 1 сокет × 8 ядер, 16 ГиБ | Для Proxmox — VirtIO SCSI PCI, `scsi0` и `scsi1` | 5 × E1000 |

Параметры T10 взяты из локального шаблона ESXi v2 для первого запуска. Для T35 FusionCompute приведены значения заводского OVF. Для Huawei Cloud и EN указаны конфигурации прежнего стенда Proxmox. В шаблоне VMware для EN использовался LSI Logic Parallel SCSI.

## Проверка файлов после копирования

Перед первым запуском выполните команду из каталога с четырьмя парами дисков, поместив в него файл `SHA256SUMS`. Она проверит все восемь QCOW2 по [контрольным суммам SHA-256](SHA256SUMS).

```sh
shasum -a 256 -c SHA256SUMS
```

Для исходного комплекта команда выводит восемь строк с результатом `OK`. При записи гостевой ОС в рабочую копию диска её контрольная сумма изменится.

Для проверки целого OVA вычислите SHA-256 архива и сравните результат со значением в таблице. Например, для T10 из каталога с дисками QCOW2, если OVA лежит уровнем выше, выполните команду ниже.

```sh
shasum -a 256 ../OceanStor_eStor_T10_ESXi_v2.ova
```

| Пакет OVA | SHA-256 |
|---|---|
| T10 ESXi v2 | `a3d0bc9bfad0681a96b82ecc654fd92907dfff8c39355406d417c11012ab85fa` |
| T35 ESXi8 EN | `84e8170da5a8f5e009745edbaa7aa90b060f0eae58070f1ec9cbe02b11811b85` |
| T35 FusionCompute | `6b4f49adfae8d32f855cb6f473ed9407879abbc3492c035b391fd28f5ed0efdf` |

Содержимое всех трёх OVA сверено с распакованными файлами. Для двух пакетов VMware также проверены SHA-256 описания OVF и обоих VMDK по манифестам MF. Проверка архивов проводилась без развёртывания на ESXi или FusionCompute.

Все восемь образов прошли проверку структуры `qemu-img check`. При подготовке комплекта загрузка этих файлов в ВМ не проверялась. В прежнем тесте на Proxmox исходный T35 Huawei Cloud и сборка T35 EN запустили `app_data` и дошли до запроса нового пароля в CLI. [Результаты испытания на Proxmox](../OceanStor_eStor_T35_work/T35-ESXi8-instruction.ru.md#7-граница-подтверждённого-результата)
