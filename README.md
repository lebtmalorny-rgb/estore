# OceanStor eStor для VMware ESXi / vSphere

Лабораторный одноконтроллерный эмулятор Huawei OceanStor, упакованный в OVA/OVF из
`Vmware_OceanStor_eStor_V1R1C00T10_single_controller.vmdk`.

Образ содержит профили **Dorado V3**: `5000_SAS`, `6000_SAS`, `5000_NVME`.
Внутри — EulerOS 2.0 SP3, компонент OSM версии `V300R003C00`, сборка от 18.12.2018.
Это учебный стенд; он не подтверждает совместимость с Dorado V6 или поведение
физического массива. При упаковке содержимое системного диска сохранено.

## Образ и конфигурация

Для установки нужен **`OceanStor_eStor_T10_ESXi.ova`** — около **398 MiB**.
В этом репозитории размещена инструкция; сам образ передаётся отдельно.

| Параметр | Значение |
| --- | --- |
| Процессор / память | 4 vCPU / 8 GiB RAM |
| Оборудование / загрузка | VMware hardware version 10 / BIOS |
| Контроллер дисков | LSI Logic Parallel |
| Системный диск | 20 GiB, SCSI 0:0 |
| Диск данных | 40 GiB, SCSI 0:1, изначально пустой |
| Сеть | 6 × E1000, общая логическая сеть `eStor-Lab` |

Это стартовая конфигурация пакета, а не измеренные минимальные требования.
При первом запуске эмулятор самостоятельно форматирует второй диск в ext3
и использует его для данных. Сохраняйте порядок дисков и оставьте этот диск пустым.

## Установка

1. Подготовьте OVA, datastore и лабораторную port group с доступом с вашего компьютера.
2. В **ESXi Host Client** выберите **Create/Register VM → Deploy a virtual machine
   from an OVF or OVA file**. В **vSphere Client** — **Deploy OVF Template**.
3. Выберите `OceanStor_eStor_T10_ESXi.ova`, задайте имя ВМ и datastore.
   Для дисков выберите **Thin provisioning**.
4. Сопоставьте сеть **`eStor-Lab`** с подготовленной port group. Все шесть адаптеров
   используют эту сеть; проверьте, что они подключаются при включении ВМ.
5. Проверьте параметры по таблице, включите ВМ и откройте её консоль.
6. По подсказкам eStor задайте IP управления, маску и шлюз. Выберите серийный номер
   из показанного списка — поле ввода ожидает его последние две цифры.
   Выберите модель: `1` — 5000 SAS, `2` — 6000 SAS, `3` — 5000 NVMe.
   Проверьте настройки и подтвердите их словом `yes`.
7. Дождитесь запуска сервисов и откройте **`https://<IP-управления>:8088`**.
   Войдите с учётными данными вашего дистрибутива eStor и выполните начальную
   настройку DeviceManager. Для доступа из другой сети должен быть доступен TCP 8088.

Адрес DeviceManager соответствует [руководству Huawei Dorado V3](https://www.manualslib.com/manual/1678780/Huawei-Oceanstor-Dorado-V3-Series.html?page=18).
Если интерфейс не открывается, сначала проверьте состояние ВМ в консоли,
port group/VLAN, IP и доступность TCP 8088.

**Вариант OVF:** используйте `OceanStor_eStor_T10_ESXi.ovf` и оба файла
`OceanStor_eStor_T10-system.vmdk`, `OceanStor_eStor_T10-data.vmdk` из одного каталога.
Файл `OceanStor_eStor_T10_ESXi.mf` содержит контрольные суммы и должен оставаться рядом.
Диски `streamOptimized` рассчитаны на импорт через мастер OVF/OVA.

## Проверка пакета

SHA-256 файла `OceanStor_eStor_T10_ESXi.ova`:

```text
c381294fa91529e38dbe9d8d79d4d1fb6ce0cd7e4ab079ddf83507075151817c
```

Проверены схема OVF, структура OVA, контрольные суммы и оба VMDK.
`qemu-img compare` подтвердил совпадение системного диска с исходником.
**Фактический импорт, загрузка и работа сервисов на ESXi пока не проверены.**
